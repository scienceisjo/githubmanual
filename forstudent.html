GitHub 가입하기

GitHub는 내 파일을 올려두고 인터넷에 공개할 수 있는 곳이야. 무료로 가입하면 돼!

github.com 접속→Sign up→가입 완료
  • 주소창에 github.com 을 입력해 접속 → 오른쪽 위 Sign up 클릭.
  • 이메일 주소 입력 → Continue.
  • 비밀번호 만들기 (영어+숫자 섞어서) → Continue.
  • 사용자 이름(Username) 정하기 — 남이 안 쓰는 영어 이름으로. → Continue.
  • ‘사람인지 확인’ 퍼즐이 나오면 풀고 끝내기.
⚠️ 사용자 이름(아이디)은 신중하게!
가입할 때 정한 사용자 이름이 곧 내 사이트 주소가 돼. 예) 아이디가 hong-science면 → 내 주소는 hong-science.github.io/... 로 시작해. 기억하기 쉬운 걸로 정하고 잘 적어두자 (STEP 8에서 써!).
📶 교실 꿀팁
같은 와이파이로 여러 명이 한꺼번에 가입하면 막힐 수 있어. 그러면 휴대폰 핫스팟으로 가입해 봐.
✅ 완료!
로그인된 GitHub 화면이 보이면 가입 끝!

내 코드가 ‘HTML’이 맞는지 확인 중요

이제 Gemini로 가자! GitHub Pages는 HTML만 인터넷 페이지로 보여줄 수 있어. Gemini가 가끔 HTML이 아닌 코드를 줄 때가 있어서, 이걸 먼저 확인해야 헛고생을 안 해.

👀 Canvas 코드의 맨 윗줄을 봐! (그림/화면만 보이고 코드가 안 보이면 ‘코드(Code)’ 보기로 바꿔서 확인해.)

✅ 이렇게 시작하면 OK!
<!DOCTYPE html><html lang="ko">
❌ 이렇게 시작하면 아직 HTML이 아니야
import React from "react"function App() { ... }def main(): (← 파이썬)```jsx / ```python
⚠️ HTML이 아니면?
아래 마법의 문장을 복사해서 Gemini 채팅에 그대로 붙여넣어 줘. 그러면 HTML 파일로 다시 만들어 줄 거야.
GEMINI에 붙여넣기 지금 만든 걸 HTML 파일 하나로 다시 만들어줘. HTML, CSS, JavaScript를 전부 한 파일에 넣고, 맨 윗줄은 <!DOCTYPE html> 으로 시작하게 해줘. 다른 파일 없이 이 파일 하나만으로 작동해야 해.
✅ 통과 기준
코드 맨 윗줄이 <!DOCTYPE html> 이 되면 합격! 다음 단계로 ㄱㄱ

Canvas에서 다운로드 버튼 누르기

Gemini Canvas 화면 위쪽(오른쪽 위)을 보면 다운로드 아이콘(⬇️)이 있어. 복사할 필요 없이 그 버튼만 누르면 파일이 바로 내려받아져!

Canvas 위쪽→⬇️ 다운로드 아이콘 클릭→파일 저장됨
  • Canvas 위쪽의 ⬇️ 다운로드(Download) 아이콘을 클릭.
  • 파일이 ‘다운로드’ 폴더에 저장돼. (보통 화면 아래나 브라우저에 ‘다운로드됨’이라고 떠.)
✅ 확인
내려받은 파일 이름이 ....html로 끝나면 잘 받은 거야! 더블클릭하면 브라우저에서 바로 작동하는지 볼 수 있어 🎉

파일 이름 정하기 중요

내려받은 파일을 어떻게 부를지 정하는 단계야. 아래 두 방법 중 하나만 고르면 돼.

😎 방법 A — 제일 쉬움 (파일 1개일 때 추천)
파일 이름을 index.html로 바꾸기. 그러면 주소 끝에 아무것도 안 붙여도 자동으로 열려!
이름 바꾸는 법: 파일 마우스 오른쪽 클릭 → 이름 바꾸기 → index.html 입력. (전부 소문자, 끝이 .html인지 확인!)
📂 방법 B — 이름 그대로 두기 (파일이 여러 개일 때)
파일이 여러 개라 전부 index.html로 할 순 없잖아? 그럴 땐 이름을 그대로 둬도 돼. 대신 그 파일 이름을 기억해 둬 — 나중에 링크 끝에 붙여서 들어갈 거야(STEP 8에서 설명!).
예: game.html, quiz.html 처럼.
⚠️ 이것만 조심!
이름 끝은 꼭 .html 하나로! index.html.txt 나 game.html.html 처럼 되면 안 돼. (윈도우에서 파일 끝이 안 보이면, 탐색기 보기 → 파일 확장명에 체크하고 확인해.)

새 저장소(Repository) 만들기

다시 GitHub로! ‘저장소’는 내 파일을 올려두는 방이라고 생각하면 돼.

오른쪽 위 ＋→New repository
  • 오른쪽 위 ＋ → New repository 클릭.
  • Repository name: 띄어쓰기 없이 영어로 아무거나. (예: my-first-web)
  • Public을 꼭 선택! (Private이면 친구가 못 봐!)
  • 초록색 Create repository 누르기.
🔗 알아두기
여기서 정한 저장소 이름도 내 주소에 들어가 → (아이디).github.io/저장소이름/ (STEP 8에서 확인!)

내 파일 올리기

Add file ▾→Upload files→파일 끌어다 놓기→Commit changes
  • Add file → Upload files 누르기.
  • 내려받은 파일을 화면 안으로 끌어다 놓기. (파일이 여러 개면 한꺼번에 다 끌어다 놓아도 돼. 또는 ‘choose your files’로 선택)
  • 아래로 내려서 초록색 Commit changes 누르기.
⚠️ 주의
폴더째 올리지 말고 파일들만 올려. 저장소 첫 화면에 .html 파일이 바로 보여야 해(폴더 속에 숨으면 안 돼).

7

GitHub Pages 켜기

⚙️ Settings→Pages→Branch: main / (root)→Save
  • 저장소 화면 위쪽 메뉴에서 Settings(톱니바퀴) 클릭. (맨 오른쪽 위 ‘내 프로필’ 설정 말고, 저장소 안의 Settings야!)
  • 왼쪽 메뉴에서 Pages 클릭.
  • Source를 ‘Deploy from a branch’로 두고, Branch는 main, 폴더는 / (root) 선택 → Save.
💡 헷갈림 주의
GitHub엔 Settings가 두 군데 있어. 저장소 이름이 위에 보이는 화면의 Settings를 눌러야 Pages가 나와!

내 링크로 들어가기 (조금만 기다려!)

1~2분 기다린 다음 Pages 화면을 새로고침하면 기본 주소가 떠. 주소는 이렇게 생겼어:

🧱 주소 = 아이디 + 저장소 이름
https://(내아이디).github.io/(저장소이름)/
(내아이디) = STEP 1에서 정한 사용자 이름 · (저장소이름) = STEP 5에서 만든 저장소 이름
① 파일 이름이 index.html이면
주소 끝에 아무것도 안 붙여도 자동으로 열려.
https://(내아이디).github.io/(저장소이름)/
② 파일 이름이 다르면 (예: game.html)
주소 맨 끝에 그 파일 이름을 붙여야 열려!
https://(내아이디).github.io/(저장소이름)/game.html
파일이 여러 개면 각각 주소 끝에 이름을 붙여서 들어가면 돼 → .../quiz.html, .../map.html …
⏳ 바로 안 떠도 괜찮아
처음엔 시간이 좀 걸려. 1~2분 더 기다렸다가 강력 새로고침 Ctrl+Shift+R (맥 ⌘+Shift+R) 해봐.
🎉 다 됐다!
이제 이 링크를 친구·가족한테 보내서 자랑하면 돼. 너는 이제 ‘배포’할 줄 아는 사람이야!

index.html이 아니면 주소 끝에 파일 이름을 붙여야 열려 → .../game.html (STEP 8 참고).

Gemini 코드가 HTML이 아니야
맨 윗줄이 <!DOCTYPE html>이 아니면 안 돼. STEP 2의 마법의 문장으로 다시 받기.
🔒
저장소가 Private이야
Public이어야 보여. Settings에서 바꾸거나 Public으로 새로 만들기 → STEP 5.
🔌
Pages를 안 켰어
파일만 올리면 끝이 아니야. Settings → Pages에서 켜야 링크가 생겨 → STEP 7.
⏱️
너무 빨리 확인했어
올리자마자는 안 떠. 1~2분 기다리고 강력 새로고침.
🔎 안 될 때, 스스로 점검 (눌러서 체크!)
  • ✓파일 이름이 index.html이거나, 아니면 주소 끝에 파일 이름을 붙였다 (예: /game.html)
  • ✓코드 맨 윗줄이 <!DOCTYPE html> 또는 <html>
  • ✓저장소가 Public
  • ✓내 .html 파일이 저장소 첫 화면에 바로 보임 (폴더 안 ❌)
  • ✓Pages에서 main / (root)로 Save함
  • ✓1~2분 기다린 뒤 강력 새로고침함
위가 전부 ✅인데도 안 보이면, 주소창에 파일 이름까지 직접 쳐보자 →
https://(내아이디).github.io/(저장소이름)/파일이름.html
(index.html이면 .../index.html) 그래도 안 되면 STEP 2(코드가 HTML 맞는지)와 STEP 4(이름 끝이 .html인지)를 다시 확인!
